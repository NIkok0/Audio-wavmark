本文档用于定义可衡量的服务目标，支撑监控、告警、值班与发布决策。

- Runbook：[`RUNBOOK.md`](./RUNBOOK.md)
- 部署文档：[`DEPLOY-SERVER.md`](./DEPLOY-SERVER.md)
- 测试与检查：[`REQUIREMENTS-CHECKLIST-AND-TEST-CASES.md`](./REQUIREMENTS-CHECKLIST-AND-TEST-CASES.md)

---

## 1. 服务范围

- API 服务：`backend-java`（认证、文件、任务、管理）
- 异步任务链路：Redis Stream + Python Worker
- 对象存储链路：COS/MinIO

---

## 2. SLI 定义

### 2.1 可用性 SLI

- 指标：`2xx/3xx` 成功请求数 / 总请求数
- 统计范围：核心业务接口（`/api/v1/auth/**`、`/api/v1/files/**`、`/api/v1/jobs/**`）

### 2.2 延迟 SLI

- 指标：核心读接口 `P95`、核心写接口 `P95`
- 统计窗口：5 分钟 / 1 小时

### 2.3 任务处理 SLI

- 指标：任务从 `queued` 到终态（`success`/`failed`）的耗时
- 指标：任务失败率（按算法类型分组）

---

## 3. SLO 目标（初版建议值）

| 目标项 | 目标值 | 统计周期 |
|--------|--------|----------|
| API 可用性 | >= 99.9% | 月 |
| 核心读接口 P95 | <= 300ms | 日 |
| 核心写接口 P95 | <= 800ms | 日 |
| 任务 30 分钟完成率 | >= 99% | 日 |
| 任务失败率 | <= 1% | 日 |

> 初版目标可先“宽后严”，每月复盘后调整。

---

## 4. SLA 对外承诺（可选）

- 若对外提供正式 SLA，请明确：
  - 统计口径
  - 例外条款（第三方依赖故障、不可抗力）
  - 补偿与通知机制

---

## 5. 错误预算与发布策略

- 月度错误预算 = `1 - SLO`
- 当月预算消耗 > 50%：冻结高风险变更
- 当月预算消耗 > 80%：仅允许故障修复与稳定性变更

---

## 6. 告警阈值建议

- API 5xx 比例连续 5 分钟 > 2%
- 核心接口 P95 连续 10 分钟超过阈值
- Redis Stream backlog 连续增长 15 分钟
- Worker 不可用超过 3 分钟

---

## 7. 观测与报表

- 关键图表：可用性、延迟、任务积压、任务失败率
- 值班日报：前一日 SLO 达成情况 + 异常摘要
- 月度复盘：目标达成、预算消耗、改进计划
