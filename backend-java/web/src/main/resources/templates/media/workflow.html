标题

此页为 Thymeleaf 壳层；实际上传、STS、水印任务等请调用既有 REST 接口：

  • POST /api/v1/storage/sts、POST /api/v1/files/complete（对象存储直传）
  • POST /api/v1/files（本机 multipart）
  • POST /api/v1/jobs/watermark（入队）
  • GET /api/v1/files、GET /api/v1/files/{id}

后续可在此页接入与 Flask 相同的 Dropzone / 表单，并继续通过 fetch 调 API。
